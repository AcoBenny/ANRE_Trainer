## Critical source-fidelity violations, precise cases
1. **G1-ELE-152**: original 2024 row159 has **“Mărimea adimensională”**; canonical stem dropped “adimensională”. Same physical concept as G2-ELEC-290, whose stem retains source wording. Independent physics note: propagation constant `gamma=alpha+j*beta` is conventionally 1/length (not unitless), whereas `gamma*length` is dimensionless; see [Engineering LibreTexts](https://eng.libretexts.org/Bookshelves/Electrical_Engineering/Electronics/Microwave_and_RF_Design_II_-_Transmission_Lines_%28Steer%29/02%3A_Transmission_Lines/2.02%3A_Transmission_Line_Theory). **Original source itself may contain a physically misleading attribute**: do not silently correct or approve.
2. **G1-ELE-247 and G2-ELEC-383**: original workbook B254 says **“prin inducţie electromagnetică”**, canonical B says **“prin inducţie electrostatică”**. This is a substantive modification of the offered answer, not spelling normalization; original statement should be preserved as provenance, regardless of whether electrostatic induction is technically intended.
3. **G1-NOR-048**: original G1 norms A55 has A “numai direct din tabloul de distribuţie”, B “numai dintr-un circuit de iluminat normal”, C “dintr-un circuit de prize”. Canonical A rewrites as a **three-method enumeration**, B and C also change. Read local I7 consolidated 2023 §5.4.13 (p70), which **permits all three methods**. Therefore **source original C is technically permissible**, while the source A/B exclusive “numai” assertions fail; canonical rewritten A fits all three methods. **Never treat canonical A as the answer letter to source XLSX A55.** Original source does not contain an independently certified answer-key column. This discrepancy should be labelled `EXPLICIT_SOURCE_DIVERGENCE_AND_KEY_LETTER_NONTRANSFERABLE` until approved changes.
4. **G1-NOR-072**: original workbook B79 says **“deconectat uşor, fără utilizarea unei scule”**; canonical B says **“deconectabilă numai prin intermediul unei scule”**. Local I7 consolidated 2023 §5.5.2.3 (p72) matches the **rewritten canonical B**, not original B; source C “trebuie să poată fi deconectat individual” is **true but incomplete** to full provision. **Original B is contradicted by norm**; imported B answer must NOT be inferred as original workbook key. Distinguish original fact from editorial rewrite.
5. **G1-ELE-154 and G2-ELEC-292**: source Excel A161 option cells B/C are numbers `1` and `0`; canonical stores textual “1” and “0”. This is **type-only**, not semantic. Three options remain equivalent.

- **PE 155/1992** read in historical [RENEL PDF reproduction](https://www.baluna.ro/wp-content/uploads/2018/02/pe_155_92.pdf). It actually includes exact:

  - for `G1-NOR-031`, §3.2.3: PE bonding in branch box to earthing bar, at consumer distribution panel to designated terminal on metal frame. B matches; A/C arbitrary conditions.
  - PE155 itself is approved by **RENEL Decision nr.232/07.04.1992**, not by its own normative code; the official 2013 Portal Legislativ [methodology](https://legislatie.just.ro/Public/DetaliiDocument/152201) notes this norm was not published in Monitorul Oficial, so historic PDF authenticity and applicability to 2026 must be treated separately from readable paragraph.
- **PE 102/1986** read historical [MEE PDF reproduction](https://electrician365.ro/wp-content/uploads/2019/04/Normativ-instalatii-electrice-ORDIN-PE-102-1986.pdf): 2.12 allows local heating **or manufacturer-approved lower-temperature installation**; NOR023 A is sufficient under source scope, not an exhaustive list. §§4.5.3/4.6.4 prohibit interruption/fuses on PE (NOR024/NOR026). The norm is approved by a **ministerial order**, not the code `PE102`.
- **I7-2011 consolidated 2023** read *from user Library PDF* `803493174-I7-2011-completat2023.pdf` (printed “forma sintetica pentru data 2023-09-22”, 249 pages), edition not claimed automatically 2026-current. Exact passages:

  - NOR012 §5.1.7.2(a) (p49) prescribes Cu for critical loads **when calculated Al cross-section <10 mm²**, so “întotdeauna Cu” in B overgeneralizes, **C conditional candidate**.
  - NOR024 §5.5.3.5 p72 forbids PE switching devices; tool-detachable test joint is not a switch.
  - NOR026 §5.5.3.5 p72 and PE102 4.6.4 prohibit fuses on PE/PEN, A source-supported.
  - NOR090 §5.2.12.2.12 p61 permits metal tubes direct on combustible construction, but §3.0.3.7 p13 adds external conditions, so **B/C can both be true**; imported B not certified as unique.
  - Prior NOR028 correction: §5.2.6.6 **does have exceptions** for mobile-receiver contact lines and free-installed conductors on properly dimensioned support, contradicting an unqualified universal prohibition. Keep old conclusion versioned/superseded, not erased.
