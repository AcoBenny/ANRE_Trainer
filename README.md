# ANRE Trainer

Unified Android trainer for ANRE electrician exam preparation.

- Grad I: 414 questions
- Grad II: 408 questions
- Combined: 822 questions
- Offline WebView application
- Local progress/statistics

## Project Journey

The repository keeps a chronological development record covering the question audit, official-source discovery, I7 verification, legislation and electrotechnics verification, documentation cards, HTML validation and Android packaging.

See [PROJECT_JOURNEY.md](PROJECT_JOURNEY.md).

## Documentation and evidence

The project distinguishes between official verification, official references and technical cross-reference evidence. This is intentional: not every technical examination question has a single official normative document behind it.

See [CHANGELOG.md](CHANGELOG.md) for major milestones and corrections.
